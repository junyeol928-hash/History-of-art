# 世界美術史 ─ 展覧会がもっと面白くなる読み物

洞窟の壁に手を押しつけた誰かから、いまの美術館まで。
覚えるためではなく、次の展覧会のために読む美術史のサイトです。

- 全38章。1章10〜15分の読み物
- 各章に本物の作品画像と、自作の図解
- 各章末に**「この章の作品を見に行く」**（日本で見られる場所を先に）
- 大年表・地図・用語辞典・美術館ガイド

ビルド不要の静的サイトです。`index.html` をブラウザで開けば動きます。

---

## 中身

```
index.html          目次
chapters/*.html     本編38章
timeline.html       大年表（西洋・日本・中国・イスラームを横に並べる）
map.html            美術の首都の移動（本物の地図タイル＋歴史の層）
museums.html        美術館ガイド（地図つき、全項目にGoogleマップリンク）
glossary.html       用語辞典
assets/css/site.css デザイン体系
assets/js/          画像解決・拡大ビューア・用語ツールチップ ほか
data/               章・作品・用語・年表・地図・美術館のデータ
tools/              マニフェストの結合と、作品画像の取得
```

### データの流れ

章を1本書くと、その章のフォルダに2つの断片ができます。

```
data/art/<章>.json     … その章で使う作品（作者・所蔵・Commonsのファイル名など）
data/terms/<章>.json   … その章で導入する用語の定義
```

`node tools/merge.mjs` がこれを束ねて、サイトが読む `data/artworks.json` と
`data/glossary.json` を作ります。章ごとにファイルを分けているので、
何人で並行して書いても衝突しません。

## 作品画像のしくみ ─ 三段構え

作品写真は**リポジトリに焼き込む**のが第一候補です。GitHub Actions が
Wikimedia から取得してコミットします。

```
1. assets/artworks/<id>.jpg        焼き込み済み（速い・確実・オフラインでも出る）
2. Wikimedia / Wikipedia の API     閲覧者のブラウザが実行時に取得（結果はキャッシュ）
3. 章に書かれた <svg class="fallback">  構図を抽象化した自作図
```

上から順に試し、失敗したら静かに次へ落ちます。**壊れた画像アイコンは出ません。**

### 画像を取得する

GitHub の Actions タブ →「作品画像を取得する」→ Run workflow。
`data/art/**` を push したときにも自動で走ります。

実行後、Actions のサマリーに**取得できなかった作品の一覧**が出ます。
`data/art/<章>.json` の `commons` / `wiki` / `wikiEn` を直して、もう一度回してください。
この3つは独立した3回のチャンスなので、ひとつ当たれば画像が出ます。

手元で回すこともできます（外に出られるネットワークが必要）。

```bash
node tools/merge.mjs
node tools/fetch-artworks.mjs          # 未取得のものだけ
node tools/fetch-artworks.mjs --force  # 全部取り直す
```

### 著作権

- 掲載するのは**作者の没後70年を超えた作品**だけです。
- 20〜21世紀の、権利が存続している作品は画像を載せません。
  代わりに自作の様式解説図で扱い、所蔵先を明記して読者が実物に会えるようにしています。
- 図解・地図・年表・章扉の図版はすべて自作です。

## 章を1本書き足すには

1. `data/chapters.json` に項目を足す（すでに38章ぶん入っています）
2. `docs/CHAPTER_KIT.md` を読む
3. `chapters/17-impressionism.html` を見本にして書く
4. `data/art/<章>.json` と `data/terms/<章>.json` を書く
5. `node tools/merge.mjs`

目次は `chapters/` に実体があるかどうかを見て、リンクにするか「準備中」にするかを
自動で切り替えます。手で書き換える必要はありません。

## デザインについて

- **昼は「美術館の白」** ─ 生成りの壁、極細の罫線、たっぷりの余白。作品がいちばん強い
- **夜は「夜の美術館」** ─ 閉館後の展示室。墨色の地に真鍮の細線、作品が発光して見える
- **時代色は、その時代に実際に使われた顔料から**採っています。
  先史＝赭土、古代＝エジプシャンブルー、中世＝ラピスラズリ、ルネサンス＝テラヴェルデ、
  バロック＝アンバー、ロココ＝ローズマダー、印象派＝コバルトヴァイオレット、
  20世紀＝カドミウムレッド、日本＝弁柄、中国＝松煙墨、イスラーム＝トルコ青。
- 章扉の特大の年号は、その章を一言で表す数字です。

配色は右上のボタンで切り替えられます（記憶されます）。
