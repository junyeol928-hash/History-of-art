あなたは「美術史を物語として読ませる学習サイト」の**章扉＋本文冒頭**を1枚のアートボードとして
デザインする。4人のデザイナーが同じ原稿を別々の世界観で組み、依頼者が見比べて1案を選ぶ。
**原稿は1文字も変えない。** 差が出るのはタイポグラフィ・色・レイアウト・装飾・図版の扱いだけ。

読者：美術館・展覧会めぐりが好きな日本語話者の社会人。専門家ではない。
サイト全体は「先史〜現代＋日本・東洋・イスラーム」までの通史を、物語として楽しく通読させるもの。

**章ラベル**：第 9 章
**章番号（欧文）**：IX
**時代・場所**：19世紀後半 ／ パリ
**タイトル**：光を追いかけた三十年
**サブタイトル**：印象派　1874–1886

**リード文（本文1段落目）**
1874年4月15日、パリのキャピュシーヌ大通り35番地。写真家ナダールの空きスタジオに、サロンで落選を重ねた画家たちが、自分たちだけの展覧会を開いた。批評家ルイ・ルロワは、モネの一枚に付けられた《印象、日の出》という題名をつかまえて、こう書いた——「印象派の展覧会」。嘲笑のつもりだった。その言葉が、美術史でいちばん有名な運動の名前になった。

**本文2段落目**
彼らが捨てたのは、アトリエの茶色い影だった。チューブ入り絵具が発明され、絵具を持って戸外へ出られるようになった。鉄道が郊外を近くした。画家たちはセーヌ川のほとりに立ち、水面で刻々と変わる光を、混ぜない絵具の点で並べていった。輪郭線は消え、代わりに空気が描かれた。

## 技術仕様（厳守）

### 図版の描き方 ─ ここが最重要
このアートボードは**外部ネットワークにアクセスできない**（画像URLは一切読み込めない）。
だから《印象、日の出》もルノワールも、**インラインSVG／CSSで、あなた自身が原画から抽象化した色面**として描く。
- 実作品の複製ではなく、**構図と色調を抽出した抽象**にすること（港・靄・オレンジの日輪・水面の反射／群衆と木漏れ日の斑点、といったレベル）。
- 「画像がここに入ります」というグレーの箱は禁止。**ちゃんと美しい色面を描く。**
- 完成サイトでは本物の作品写真が入る前提なので、図版枠のプロポーション（横長 4:3 など）は実寸に合わせる。
- キャプション・所蔵館表記は必ず添える（美術館の壁のキャプションのように）。

### アートボードのサイズ
ルート要素は **幅 1000px 固定・高さは内容なり（目安 1400〜1600px）**。
`w`/`h` はフレーム側で指定するので、ルートは `width: 1000px` を明示すること。
背景色は必ずルートに明示（透明にしない）。

### ファイル形式（Design Component `.dc.html`）
```html
<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <script src="./support.js"></script>
</head>
<body>
<x-dc>
<helmet>
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=...&display=swap">
  <style>
    body { margin: 0; }
    a { color: #...; } a:hover { color: #...; }
  </style>
</helmet>
<div style="width: 1000px; background: #...; ...">
  ... 中身 ...
</div>
</x-dc>
</body>
</html>
```
- `<script src="./support.js"></script>` の行は**一字一句そのまま**。
- 静的なアートボードなので `<script data-dc-script>` は**書かない**（空だとエラーになる）。
- すべての要素を閉じ、すべての属性をクォートする。
- **スタイルはインライン `style="..."` を基本**にする（プロパティパネルで編集できるようにするため）。
  Webフォント読み込みと `a` の色だけ `<helmet><style>` に置く。
- 並ぶ要素（年表の項目、用語チップ等）は `display: flex` / `grid` ＋ `gap` で組む。
  マージンや空白文字で並べない。
- アイコンが要るならインラインSVG（線画・24pxグリッド）。**絵文字は禁止。**
- `{{ }}` は使わない（静的なので不要）。

### フォント
Google Fonts のみ読み込み可（`fonts.googleapis.com`）。日本語で使えるもの：
Noto Serif JP / Noto Sans JP / Shippori Mincho / Shippori Mincho B1 / Zen Old Mincho /
Zen Kaku Gothic New / Zen Antique / Klee One / M PLUS 1 / Kaisei Decol / Yuji Syuku
欧文：Cormorant Garamond / EB Garamond / Playfair Display / Bodoni Moda / Spectral /
Libre Baskerville / Instrument Serif / DM Serif Display / Archivo / Syne / Space Grotesk / Jost
- **Inter・Roboto・Arial・Fraunces は使用禁止。**
- フォントは1〜3種まで。必ず fallback スタック付き（例：`'Shippori Mincho', 'Yu Mincho', serif`）。
- 本文は16px以上、行間1.9前後。日本語の可読性を最優先。

### 品質基準
- 「AIっぽい」装飾（意味のないグラデーション背景、角丸＋左ボーダーのカード、絵文字）は禁止。
- 余白・階層・リズムで語る。要素を足して埋めない。
- グレースケールにしても階層が壊れないこと。
