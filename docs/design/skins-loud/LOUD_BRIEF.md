# 時代スキン ── 大胆版

## 前提

一度、控えめな版を作った。依頼主の評価は「**もっと一目でその時代の特徴がわかるようにしてほしい。
その上である程度の統一感は保ちたい**」。
つまり前回は慎重に振りすぎた。今回は**思い切り振る**。

ただし闇雲に派手にするのではない。**変える場所を固定し、その場所の中では大胆に変える。**
統一感は「装飾の控えめさ」からではなく「**骨格の一貫性**」から生む。

前回の控えめ版は `/home/user/History-of-art/docs/design/skins/` にある。
自分の担当時代のものを読んで、**そこからどれだけ振れるか**を考えること。前回版の焼き直しは無価値。

---

## 今回、大胆に変えてよいもの

### 1. 章扉を「門」にする ← 最重要
装飾されたヘッダーではなく、**ほぼ全画面（1000 × 700〜900px）の、その時代そのものの面**にする。
読む場所ではなく**入る場所**。ここが「一目でわかる」の主戦場。
地の色・素材・文字組み・図像を、完全にその時代の言語で構成してよい。
本文の可読性の制約はここには及ばない（本文ではないので）。

### 2. 本文の地の色を変えてよい
前回は生成り #f4f1e8 で固定させたが、今回は**時代ごとに変えてよい**。
条件は2つだけ：**明るい面であること**（明度0.85以上）と、**本文色とのコントラスト比7:1以上**。
中世なら少し深い羊皮紙色、20世紀なら冷たい白、日本なら生成りに黄味、のように部屋の壁の色が変わる。

### 3. 節の区切りに「全幅の帯」を1〜2回
本文の幅を超えて左右いっぱいに広がる、その時代の造形の帯。
写本の欄外飾り、ロカイユのカルトゥーシュ、原色のバー、料紙の継ぎ目。
**章に1〜2回まで。** 3回以上出すと壁紙になる。

### 4. 「この時代の見分け方」ブロック ← 必ず入れる
**3つのしるし**を、あなたが描く図で示す定番ブロック。
例）ゴシックなら「尖ったアーチ／背の高い窓／細く分かれた柱」を線画で並べ、
それぞれ一行で「これがあればゴシック」と言い切る。
**これは装飾ではなく本文の一部**であり、美術史の学習そのものになる。読者が美術館で使える形にすること。

### 5. 見出し・数字の書体、罫線、区切り飾り、図版の額（前回と同じく変えてよい）

---

## 絶対に固定するもの（＝統一感の正体）

これらが全章で同一だから、表面をどれだけ振っても一冊の本に見える。

- **本文1行の長さ**（読み幅）と**行間 2.0** と**段落の間隔 1.5em**
- **本文のサイズ 18px 以上**、本文は明朝系
- **見出しの階層と、その大きさの比**（章題 ＞ 節見出し ＞ 小見出し）
- **キャプションの4段構造**：作者／作品名＋制作年／技法・寸法・所蔵／「ここを見る」
- **図版がその紙面でいちばん大きく、いちばん強い**こと
- **作品画像の上に装飾を重ねない**
- 本文とその地のコントラスト比 7:1 以上

装飾は**章扉・節の区切り・余白・見出し**に置く。**本文の行の中と図版の上には置かない。**

## 作るもの

担当する章の実物HTMLを読み、**章扉（門）／「この時代の見分け方」／本文2節／図版1点／全幅の帯1つ／年表**
を1枚のアートボードに組む。幅 **1000px 固定**、高さは内容なり（3000〜4200px を想定。長くてよい）。

- 本文・キャプションの文章は**実物の章から一字も変えずに引く**
- 「この時代の見分け方」の3項目の文言は、あなたが章の内容に基づいて書いてよい（各20〜40字）
- 図版は外部から読み込めないので、構図と色調を抽象化した**自作SVG**で描く。グレーの箱は禁止

## 形式（Design Component `.dc.html`）

```html
<!doctype html>
<html><head><meta charset="utf-8"><script src="./support.js"></script></head>
<body><x-dc>
<helmet>
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=...&display=swap">
  <style> body { margin: 0; } a { color:#...; } a:hover { color:#...; } </style>
</helmet>
<div style="width: 1000px; background: #...;"> … </div>
</x-dc></body></html>
```
- `<script src="./support.js"></script>` は一字一句そのまま
- `<script data-dc-script>` は書かない（空だとエラー）
- スタイルはインライン `style="..."` 基本、Webフォントと `a` の色だけ helmet
- 並ぶ要素は flex / grid ＋ gap。絵文字禁止。`{{ }}` 禁止
