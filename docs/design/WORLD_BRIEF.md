# 時代スキン ── 世界版

2026年9月6日

## これまでと、今回の違い

三度目である。一度目は控えめに作り、二度目（`skins-loud/`）で大胆に振り、
三度目（`skins-max/`）でさらに上げた。それでも依頼主の評価は「まだ足りない」だった。

理由ははっきりしている。**三度とも、本文だけは共通の中央列に戻していた。**

| | 章扉 | 本文 |
|---|---|---|
| 控えめ版 | 装飾されたヘッダー | 771px・18px・行間2.0・横組み |
| 大胆版 | 900px高の面 | 同上 |
| MAX版 | 1300px高の面、バラ窓、金の頭文字 | **同上** |

門をどれだけ豪華にしても、くぐった先がいつもの本文なら、
「すごい表紙の下に、いつもの本が続く」という関係は変わらない。

今回、依頼主は二つの条件を自分から外した。

1. **読みづらくなってよい。** コントラスト比7:1も、明るい地も、絶対条件から外す。
2. **一冊の本に見えなくてよい。** 38章が38の別世界でよい。本文の組み方も変えてよい。

**つまり、本文に手を入れてよい。** ここが今回の主戦場である。

## 越えてはいけない線（＝新しい固定条件）

可読性の数値を外した代わりに、これを守る。装飾の控えめさではなく、
**読者が自分で進み、戻り、全文と原図に到達できること**が、今回の統一感の正体である。

1. **文章を取り出せなくしない。**
   文字が画面外で切れて戻せない、重なった段落が開けない、
   地と同化して判別できない、という状態を作らない。
   低コントラストでもよいが、全文に到達できる道は必ず残す。

2. **読む順番を永久に迷わせない。**
   紙片を散らしても二段に割っても、番号・見出し・配置から次が分かること。
   見た目の順番と文章の意味を食い違わせない。

3. **読む時間を奪わない。**
   本文が自動で消える、読んでいる行が動き続ける、
   制限時間内でしか読めない、という作りにしない。立ち止まれる場所を残す。

4. **スクロールから出られなくしない。**
   横送りに閉じ込めない。演出を飛ばして次の節へ行けるようにする。

5. **装飾を作品の事実と混同させない。**
   演出のための加工を、その作品が本来そうであるかのように見せない。
   原図の全体と、キャプションの4段（作者／作品名・年／技法・寸法・所蔵／ここを見る）には必ず戻れること。

6. **画面や入力方法で本文を落とさない。**
   スマートフォン、文字拡大、キーボード操作で、同じ内容に到達できること。
   1000px固定のアートボードでは確認できない領域なので、実機幅で必ず見る。

7. **動きを止めても読書が壊れない。**
   激しい点滅や視界全体の揺れを避ける。`prefers-reduced-motion` を尊重し、
   動きを止めても図と文章が残る構成にする。

8. **時代の記号を地域全体に雑に広げない。**
   絵巻を日本の全6章に使い回さない。ゴシックの窓を中世の全3章に流用しない。
   大胆さの根拠は、**その章が扱う作品と技法**に置く。

## 変える層

装飾を足すのではない。**紙そのものと、文字の組み方**を変える。

### 1. 紙 ── 何に刷られているか
岩肌、パピルス、大理石、羊皮紙（罫線入り）、乾いた漆喰、絹、
和紙の繊維と継ぎ目、新聞紙、方眼、美術館の白。
地の色は明るくなくてよい。群青に淡い文字、朱の面に黒文字、金地の文章もある。

### 2. 組み ── どう流れるか ← 最重要
- **縦組み**（`writing-mode: vertical-rl`）── 日本・中国。右から左へ読む。
- **二段組み＋欄外注** ── 中世の写本。装飾頭文字が段の肩を押し広げる。
- **不揃いな紙片** ── キュビスム・ダダ。中央の一本列を解体し、視線を斜めに跳ばせる。
- **新聞の割り付け** ── 19世紀。大見出し、細い段、大きな図版が同じ面を占める。
- **極端な余白** ── 水墨・山水。一文の横に画面半分の無地を残し、その後に密な面を出す。

### 3. 門 ── 入口
全画面（100vh）の、その時代そのものの面。読む場所ではなく入る場所。
**入口で約束したことを、本文が守る。** 絵巻の門をくぐったら本文も絵巻になる。
ここで共通の中央列に戻らないことが、今回の核心である。

### 4. 図版 ── 額から場面へ
額なし（先史・壁に直に描く）、金の重厚な額（バロック）、
掛軸の表装（日本・中国）、横長の連続面（絵巻）、
壁一面（バロック）、離れて点在する展示（現代）。

### 5. 動き ── 内容と結びついたものを、章に一つ
装飾のための動きは要らない。**読者が理解する瞬間と、視覚的な変化を重ねる。**
- 第7章「壁を消すための三つの部品」で、本文を囲っていた石の面が実際に抜ける
- 第28章「右から左へ、時間が流れる」で、閲覧の窓が右から左へ進む
- 第20章「一点から見るのを、やめる」で、本文の列が左右にずれる

### 6. 細部
カーソル、選択時の色、スクロールバー、読み進みの表示。
絵巻なら巻軸に収まり、中世なら窓が一つずつ灯る。

## 章の中の山

各段落で同じ強さの驚きを反復しない。**章の中で意味が変わる2〜4か所**に山を置く。
山と山のあいだは、世界観を保ったまま動きだけを落ち着かせる。無地には戻さない。

```
入口（門）      → 身体感覚を変える。時代名を読まなくても別の場所だと分かる
本文の入り     → 入口の約束を守る。ここで中央列に戻らない
転換点         → 最大の変化。理解する瞬間と視覚の変化を重ねる
章末           → 読み終えた褒美と、次章の世界を覗く開口部
```

## 作り方

`assets/css/era/<時代>.css` に時代ごとに分ける。各章は自分の時代の1枚だけを読む。

- 15枚を1つずつ作り、1つずつ見比べられる
- どの章も15時代ぶんを読み込む、という無駄がなくなる
- `file://` でもそのまま動く（同梱データの仕組みを壊さない）

共通の骨組みは `skins.css` に残し、時代固有のものを `era/` に出す。
章の中の変化に JS が要るものは `assets/js/stage.js` にまとめ、
**JSが動かなくても本文が読める**ことを条件にする。

### 時代と章の対応（15時代・38章）

| 時代クラス | 章 |
|---|---|
| prehistory | 01 |
| ancient | 02 |
| classical | 03 04 |
| medieval | 05 06 07 |
| renaissance | 08 09 10 11 |
| baroque | 12 13 |
| rococo | 14 |
| 19c | 15 16 |
| impression | 17 18 19 |
| modern | 20 21 22 |
| contemp | 23 24 25 |
| japan | 26 27 28 29 30 31 |
| china | 32 33 34 |
| islam | 35 36 |

時代クラスは土台であり、完成形ではない。
同じ日本でも縄文・仏教彫刻・絵巻・水墨・金碧・浮世絵は別の構成になる。
章ごとの上書きは `body[data-chapter="..."]` で行う。

## 進め方

1. **三つの時代を全力で作り、並べて見せる。**
   互いにいちばん遠い三つを選ぶ。
   - **japan**（縦組み・和紙の継ぎ目・掛軸の表装）
   - **medieval**（二段組み・羊皮紙・金の装飾頭文字・欄外注）
   - **modern**（不揃いな紙片・原色の面・方眼）

2. **判定は「本文だけを見て、章が違うと分かるか」。**
   章扉を隠して本文だけ並べる。それで違いが分からなければ、まだ足りない。

3. 振り幅が決まったら、残り12時代へ。

4. 最後に、章から章への移り変わりと全体の導線を整える。
