世界美術史 ─ デザイン4案

同じ原稿（第17章「光を追いかけた三十年」／印象派）を、4つの世界観で組んだものです。 本文・図版・年表・図解・美術館メモの中身は4案とも完全に同じなので、組み方だけを見比べられます。

この比較ページは外部から画像を読み込めない場所で作ったため、作品はすべて 構図と色調を抽出した自作の色面です。完成サイトでは、ここに本物の作品写真が入ります。 逆に言うと、いま見えている「絵の位置・大きさ・余白」がそのまま完成形の設計です。

A 美術館の白B 夜の美術館 C 時代がまとうD モダン・エディトリアル
A

美術館の白

生成りの壁、極細の罫線、余白。作品がいちばん強い。どの時代の絵とも喧嘩しないので、38章を通しても飽きません。

リスク：地味に見える瞬間がある。

B

夜の美術館

閉館後の展示室。作品が発光して見える没入型。バロックや現代美術が劇的に映えます。

リスク：長時間の読書では目が疲れる。金を使いすぎると一気に安っぽくなる。

C

時代がまとう

章に入るとサイトが服を着替える。いちばん「楽しい」案です。下段が着替えの見本（中世／ルネサンス／ロココ／印象派／バウハウス）。

リスク：38章ぶん作り込む必要があり、統一感の管理も難しい。制作量は最大。

D

モダン・エディトリアル

美術雑誌のアートディレクション。特大の年号、非対称グリッド、断ち切りの図版。今っぽく、かっこいい。

リスク：デザインが作品と主役を争いやすい。

4案とも、色と書体はトークン化してあります。「Aの静けさでDの特大年号が欲しい」といった混ぜ方もできます。
