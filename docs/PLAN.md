# 世界美術史 ─ 読み物サイト 設計書

## 何をつくるか

美術館・展覧会めぐりを何倍も楽しくするための、**通読できる世界美術史**。
教科書ではなく読み物。各章は「なぜこの絵はこう描かれたのか」を時代のドラマとして語る。
写真・図解・地図・年表をふんだんに使う。

- 言語：日本語
- 読者：専門家ではない、美術館好きの社会人
- 1章あたり 10〜15分の読み物（約4,000〜5,000字）＋図版6〜12点
- 端末：PC・スマホ両方を全ページ検証

## 読み物以外の仕掛け（すべて実装する）

### 1. 大年表（横断スクロール）
西洋／日本／中国／イスラームを**横に並べた**年表。同じ年に世界のどこで何が起きていたかが一目で分かる。
「《風神雷神図屏風》と《夜警》はほぼ同じ頃」のような発見が起きるように。各項目から該当章へ飛べる。

### 2. 地図（美術の中心地の移動）
自作SVGの世界地図・ヨーロッパ地図の上を、時代とともに「美術の首都」が移動していく。
アテネ→ローマ→コンスタンティノープル→フィレンツェ→ローマ→アントワープ／アムステルダム→パリ→ニューヨーク。
各章にもその章の舞台を示す小地図を置く。

### 3. 作品の読み解き（拡大・注釈）
名画を拡大表示し、「ここの手」「この光」「この床のタイル（＝遠近法）」にホットスポットを打って注釈を出す。
美術館で実際にどこに視線を置けばいいかが身につくパートで、このサイトの中核機能。

### 4. 用語辞典と検索
本文中の専門用語をタップ／ホバーするとその場で語義が出る。作家名・作品名・用語・美術館名を横断検索。

### 5. 各章末「美術館で見る」
その章の作品が日本のどこで見られるか（国立西洋美術館、大原美術館、ポーラ美術館 等）と、
海外で見るならどこか。展覧会に行く前後で開くパート。

## 画像をどう手に入れるか

このプロジェクトの一番の技術的難所。**三段構え**にする。

1. **焼き込み（第一候補）**
   `data/artworks.json` に作品マニフェスト（Wikipedia記事タイトル／Commonsファイル名／作者・年・所蔵）を持ち、
   GitHub Actions が Wikimedia から適正サイズのJPEGを取得して `assets/artworks/` にコミットする。
   取得できなかったものは失敗レポートとして出力し、マニフェストを直す。
2. **実行時取得（フォールバック）**
   焼き込み画像が無い作品は、閲覧者のブラウザが Wikipedia REST API（CORS対応）で解決して表示。
   結果は localStorage にキャッシュ。
3. **自作SVG（最終フォールバック）**
   それでも取得できない作品は、構図と色調を抽象化した自作SVGを表示する。
   **壊れた画像アイコンは絶対に出さない。**

図解・年表・地図・様式比較図はすべて自作SVG（＝確実に表示され、著作権の問題もない）。

すべての作品画像はパブリックドメイン（作者の没後70年超）を原則とし、出典と所蔵館を必ず明記する。
20世紀以降の著作権が生きている作品は画像を載せず、自作の様式解説図と所蔵館情報で扱う。

## 技術構成

- ビルド不要の静的サイト（HTML＋CSS＋素のJavaScript）。GitHub Pages で公開。
- 章は共通テンプレートから生成し、本文はデータとして分離する。
- 画像は遅延読み込み。年表・地図・拡大表示は自前実装（外部ライブラリに依存しない）。
- ダークモード対応。全ページをPC幅とスマホ幅の両方で確認する。
